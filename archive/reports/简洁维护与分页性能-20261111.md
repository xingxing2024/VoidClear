# 简洁维护与分页性能（2026-11-11）

候选：`target/VoidClear-3.0.0-maintenance-20261111-candidate.jar`。
SHA256：`45C39C852C29226DA2F77D5202E0D04086FEEBB69883971816AA485E161956CB`。

## 改动

- `TrashStore.isCurrentPage` 在锁内或已提交快照上直接核对编号与字节内容，避免每个菜单心跳反复克隆物品数据。外部 Entry 的构造与 bytes 访问仍防御性复制。
- MySQL 分页直接定位快照切片，公共返回值复制列表引用，避免从头 skip 与保留整份旧快照。切片计算归到一个私有方法。
- 两份页面比较逻辑合并为 `TrashStore.samePage`；菜单层删除重复实现。比较仍包含顺序、编号和完整物品字节，不用只比较物品数代替。
- 历史查询扫描实际归档文件，替代为每个日期尝试打开文件。归档文件日期解析只保留一份。
- 修复仅滚动普通操作日志时跳过过期归档清理的问题；未触碰交易恢复凭据。

三处生产文件的本轮改前版本见 `target/maint-backup-path.txt` 指向的目录。既有工作区改动保留。
